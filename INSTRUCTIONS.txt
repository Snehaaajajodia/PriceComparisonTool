Demo Video Link: https://drive.google.com/file/d/11wixK1eCf9FobmW3VVEoe_X795ecy6Yk/view?usp=drive_link


DESCRIPTION:
This is an advanced CLI tool that scrapes multiple e-commerce websites for price comparisons
across different countries. It uses Playwright with stealth features to avoid bot detection
and provides comprehensive price comparison data.

FEATURES:
Multi-country support (US, IN, UK, CA)
Multiple e-commerce sites per country
Stealth mode with anti-detection features
JSON file input/output support
Human-like browsing simulation
CAPTCHA detection and handling
Comprehensive logging
Price sorting and filtering

DEPENDENCIES:
-------------
1. Python 3.8 or higher
2. Playwright
3. Required Python packages (install via pip):

   pip install playwright
   playwright install chromium

INSTALLATION STEPS:
-------------------
1. Ensure Python 3.8+ is installed on your system
2. Open terminal/command prompt in the project directory
3. Install Playwright:
   pip install playwright
4. Install Playwright browsers:
   playwright install chromium
5. Verify installation:
   python advanced_price_scraper.py --help

USAGE EXAMPLES:
---------------

1. Basic Search:
   python advanced_price_scraper.py --country IN --query "iPhone 15"

2. Search with Headful Mode (see browser):
   python advanced_price_scraper.py --country IN --query "MacBook Air" --headful

3. Limit Results per Site:
   python advanced_price_scraper.py --country US --query "Nike Shoes" --max-results 5

4. Re-check Existing Links from JSON File:
   python advanced_price_scraper.py --country IN --query "Samsung Galaxy" --file previous_results.json

5. Search in Different Countries:
   python advanced_price_scraper.py --country UK --query "PlayStation 5"
   python advanced_price_scraper.py --country CA --query "iPhone 15"
   python advanced_price_scraper.py --country US --query "Nike Air Max"

CLI ARGUMENTS:
--------------
--country <country_code>    Required: Country code (US, IN, UK, CA)
--query <product_name>      Required: Product search query
--file <path>              Optional: JSON file with previously saved links to re-check
--headful                  Optional: Run browser with UI (not headless)
--max-results <number>     Optional: Maximum results per site (default: 10)

OUTPUT FILES:
-------------
1. Results JSON: <country>_<query>_results.json
   Example: IN_iPhone_15_results.json

2. Debug HTML Files: <website>_<query>.html
   Example: flipkart_iPhone_15.html

3. Log File: price_scraper.log
   Contains detailed execution logs
